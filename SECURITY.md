# Security Policy

## Supported Versions

Security fixes are focused on the current `main` branch.

## Reporting a Vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Report them privately through GitHub's repository security reporting features when available.

Include the affected file or feature, reproduction steps, impact, and any suggested mitigation.

## Scope

Reports covering script injection, unsafe DOM handling, dependency issues, data integrity, or denial-of-service behavior are especially useful.

Please allow time for investigation before publicly disclosing a confirmed issue.

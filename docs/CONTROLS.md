# Controls Reference

| Input | Action |
| --- | --- |
| Scroll | Move through the journey |
| Drag | Orbit the current world |
| Shift + wheel | Zoom |
| T | Toggle auto-tour |
| O | Toggle orbit lines |
| B | Toggle bloom |
| R | Toggle true relative scale |
| Space / Down / Page Down | Next world |
| Up / Page Up | Previous world |
| Home | Return to Sol |
| End | Jump to Pluto |
| 0-9 | Jump to a numbered world |
| Click | Focus a world |

If a keyboard shortcut does not respond, click the page first so the browser window has focus.

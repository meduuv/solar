# Browser Support

The experience requires a modern browser with JavaScript modules, WebGL, and standard pointer and keyboard event support.

Recommended browsers include current Chrome/Chromium, Firefox, Safari, and Edge releases.

## Capability notes

- WebGL support is required for the 3D scene.
- GPU capability affects bloom, device-pixel-ratio, and overall frame rate.
- Reduced-motion preferences are respected for users who prefer less animation.
- Mobile layouts are supported, but available GPU and memory can vary substantially between devices.

If the scene does not render, check WebGL availability and the browser console first.
